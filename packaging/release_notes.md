## 下载哪个？

| 文件 | 说明 |
| --- | --- |
| **VideoSorter.exe** | 单个文件，下载后双击就能用，方便拷到别的电脑。每次启动要先解压，会慢几秒。 |
| **VideoSorter-版本号-windows.zip** | 文件夹版，解压后双击里面的 `VideoSorter.exe`，启动更快。 |

两个都不需要安装 Python，也不需要另外装 ffmpeg。

第一次打开时 Windows 可能提示「Windows 已保护你的电脑」（程序没有数字签名），
点「更多信息 → 仍要运行」即可。

## 功能

* 按时长 / 帧率 / 分辨率 / 有无声音给视频分组
* 鼠标停在缩略图上自动播放预览
* 选中后按空格用系统播放器播放，双击在资源管理器中定位
